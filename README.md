# password-strength-cli

# 🇧🇷 Como instalar e executar

Após baixar o repositório pelo GitHub e extrair o arquivo ZIP, abra o terminal (Linux) ou o Prompt de Comando / PowerShell (Windows) e navegue até a pasta do projeto. Em seguida, execute o programa conforme os comandos abaixo.

# Linux

cd ~/Downloads/AtividadeExtensionista/
python main.py


# Windows

cd Downloads\AtividadeExtensionista
python main.py


É necessário ter o Python 3 instalado no sistema.
Para encerrar o programa, pressione Ctrl + C.
